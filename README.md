# Matheus Machado — Portfólio

Currículo web responsivo em HTML, CSS e JavaScript, sem framework ou etapa de build.

## Executar

Abra `index.html` no navegador ou execute `python3 -m http.server 4173` e acesse http://localhost:4173.

## Estrutura e componentes

- `index.html`: apresentação, sobre, competências, formação, projetos e contato.
- `style.css`: tema carvão/verde, grids responsivos e animações.
- `script.js`: digitação, diagrama, menu mobile, abas acessíveis, terminal demonstrativo, progresso de leitura e preparação de e-mail.
- `fonts/`: DM Sans e JetBrains Mono servidas localmente.
- `docs/`: currículo original em PDF.
- `PRODUCT.md`: perfil e restrições de conteúdo.
- `DESIGN.md`: sistema visual e componentes.

O painel de código é uma demonstração local. Não executa comandos Git ou código fornecido pelo visitante. O formulário prepara um e-mail, mantendo o envio sob confirmação no aplicativo de e-mail; não há servidor de envio configurado.

## Acessibilidade e movimento

Navegação por teclado, foco visível, rótulos de formulário, abas com setas/Home/End, conteúdo disponível sem JavaScript e suporte a `prefers-reduced-motion`. O controle no diagrama também pausa as animações.
